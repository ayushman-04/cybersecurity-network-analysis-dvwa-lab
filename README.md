# Cybersecurity Lab: Network Traffic Analysis & Web Vulnerability Testing

This project demonstrates practical exposure to cybersecurity concepts including network traffic analysis using Wireshark and web application vulnerability testing using DVWA (Damn Vulnerable Web Application).

This work was initially performed as part of academic coursework and later organized into a structured project for better documentation and presentation.

---

- Inspected packet-level data
- Analyzed protocols such as HTTP and DNS
